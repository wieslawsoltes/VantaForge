# Vanta Forge

An original, dependency-free WebGPU scene editor and executable game runtime.

Full engine/editor source, tests, documentation, and GitHub Pages deployment are being imported from the completed Vanta Forge distribution.

- Editor: https://wieslawsoltes.github.io/VantaForge/
- Standalone game: https://wieslawsoltes.github.io/VantaForge/aether-relay-game.html

Native WebGPU renderer with a WebGL2 fallback. Plain HTML, CSS, and JavaScript; no external engine dependencies.
