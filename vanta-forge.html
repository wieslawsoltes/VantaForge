Welcome to Vanta Forge

A real scene editor. A real game runtime. Your world, entirely in the browser.

Create your world

Drag actors or assets into the viewport. Select an object and drag a colored gizmo axis. Edit its components in Details.

W Translate   E Rotate   R Scale
F Focus   Delete Delete   Ctrl D Duplicate
Ctrl Z Undo   Ctrl Shift Z Redo

Bring it to life

Press Play and collect the six energy shards. Physics, animation, and graph events run at 120 fixed updates per second.

WASD Move   Space Jump
R Respawn   Esc Stop
Pause and single-step to inspect runtime state.

Build behavior

Select an Energy Shard and open its Gameplay Graph. Click an output port, then a compatible input port to connect. Click a wire to remove it. Drag nodes by their headers.

Keep and share

Save writes to local IndexedDB. Download a project from File to keep a portable JSON backup. Export game creates a single standalone HTML containing the scene, assets, shaders, and runtime.

The engine is a compact, independently implemented foundation—not Unreal Engine or a compatible replacement. Check README.md for supported formats and simulation limits.
